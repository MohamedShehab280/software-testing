Alerts & Modals

The first three are real browser dialogs: use switchTo().alert(). The last two are HTML on the page: find them like any element.

JavaScript alert switchTo().alert()

Use: driver.switchTo().alert().getText() · driver.switchTo().alert().accept()

Confirm dialog accept()dismiss()

Use: alert.accept() → You clicked OK · alert.dismiss() → You clicked Cancel

Prompt dialog sendKeys()

Use: Alert alert = driver.switchTo().alert(); · alert.sendKeys("Ali"); · alert.accept();
