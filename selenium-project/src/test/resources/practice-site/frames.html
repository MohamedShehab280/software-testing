iFrames

A frame is a page inside the page. Selenium only sees one of them at a time.

A form inside an iFrame switchTo().frame()

Use: driver.switchTo().frame("login-frame") · driver.switchTo().frame("loginFrame") · driver.switchTo().frame(driver.findElement(By.cssSelector("iframe#login-frame"))) · driver.switchTo().defaultContent()

Two frames, and a frame inside a frame IndexparentFrame()

Use: driver.findElements(By.tagName("iframe")).size() · driver.switchTo().frame(1) → Frame B · driver.switchTo().frame("nested-frame") → inside B · driver.switchTo().parentFrame() → back to B

Outside every frame defaultContent()

Note: Inside a frame, these do not exist: NoSuchElementException · driver.switchTo().defaultContent() first
