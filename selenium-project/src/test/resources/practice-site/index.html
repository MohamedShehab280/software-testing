SE2 Practice Lab

A practice ground for Selenium WebDriver in Java. Every page focuses on one kind of element, and every element has a hint with its locators.

The eight locators Reference

StrategyJavaBest for
IDdriver.findElement(By.id("first-name"))Unique elements with an id
Namedriver.findElement(By.name("email"))Form fields with a name
Class namedriver.findElement(By.className("btn-primary"))Elements sharing a class
Tag namedriver.findElements(By.tagName("input"))All elements of one tag
Link textdriver.findElement(By.linkText("Go to the Dropdowns page"))A link, by its full text
Partial link textdriver.findElement(By.partialLinkText("Dropdowns"))A link, by part of its text
CSS selectordriver.findElement(By.cssSelector("input#first-name"))Any attribute, short and fast
XPathdriver.findElement(By.xpath("//input[@id='first-name']"))Anything, even by its text

How to open this site Resources

The folder practice-site is in src/test/resources, inside your project. Open a page with its path from the project folder:

File website = new File("src/test/resources/practice-site/forms.html");
driver.get(website.toURI().toString());

Add ?hints=off to hide every hint:

driver.get(website.toURI() + "?hints=off");
