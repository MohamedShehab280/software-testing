File Upload

Uploading means sendKeys with the full path of a file. A sample file is in src/test/resources/practice-site/assets/sample.txt.

How Selenium uploads a file sendKeys

Selenium cannot use the file window of the operating system. Send the full path of the file to the <input type="file"> instead:

File file = new File("src/test/resources/practice-site/assets/sample.txt");
driver.findElement(By.id("simple-file-input")).sendKeys(file.getAbsolutePath());

Locators: By.id("simple-file-input") · By.name("simpleFile") · By.cssSelector("input[type='file']")
